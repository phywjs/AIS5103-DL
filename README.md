This site here contains example codes for AIS5103 course.  Here are some explanation of the codes:

autograd.ipynb - this example show the use of automatic differentiation for y = x*x, dy/dx = 2x and make a plot.

fit-sin-1-3-1.ipynb - this is the code to illustrate ``universal approximation theorem'' in Bishop book for sin(x) with a 1-3-1 network structure and tanh activation function 

leastsquare-nn.ipynb - do least squares fit with basis 1, x, x*x, using nn.Module

leastsquare.ipynb - simple handed code for least squares not using nn.Module

simpleNN-class.ipynb - a simple network using class

simpleNN-hand.ipynb - a simple network not using class
